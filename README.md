# Workout Tracker Backend

Overview of project setup, tools used, and API documentation.

## Tech Stack
- **Framework:** Flask (v2.2.2)
- **ORM:** Flask-SQLAlchemy (v3.0.3)
- **Migrations:** Flask-Migrate
- **Serialization:** Marshmallow

## Quick Start
```bash
pipenv install
pipenv shell
python server/app.py
```
